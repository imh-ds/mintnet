# CIN design and build documents

This directory contains the tracked source of truth for MINT's forthcoming
Conditional Predictive-Information Network (CIN) engine.

Read in this order:

1. [`methodology/methodology_outline_2026-09-19.md`](methodology/methodology_outline_2026-09-19.md)
   defines the scientific estimand, interpretation, and boundaries.
2. [`methodology/technical_implementation_roadmap_2026-09-19.md`](methodology/technical_implementation_roadmap_2026-09-19.md)
   defines the architecture, validation stages, and release gates.
3. [`methodology/feasibility_review_2026-09-19.md`](methodology/feasibility_review_2026-09-19.md)
   records corrections and the evidence status of the proposed design.
4. [`build-plan/00_README_build_plan_index.md`](build-plan/00_README_build_plan_index.md)
   expands the roadmap into twelve dependency-ordered implementation tasks.

The documents specify work that has not yet been implemented or validated.
Historical source reviews and alternative proposals remain local planning
artifacts; they are not competing build specifications. Retired executable
methodology is preserved under [`archive/`](../../../archive/README.md).

The `implementation-plans/` directory records repository-maintenance plans,
not the CIN numerical build plan itself.
